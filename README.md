\# Cinevo



Cinevo is a full-stack video-on-demand streaming platform built as a portfolio and production-oriented project.



\## Technology Stack



\### Backend

\- Python

\- Django

\- Django REST Framework

\- JWT Authentication

\- PostgreSQL



\### Frontend

\- React

\- Vite

\- JavaScript



\### Planned Infrastructure

\- Video storage

\- Video transcoding

\- Adaptive streaming

\- CDN delivery

\- Production deployment



\## Core Features



\- User registration and authentication

\- User profiles

\- Movies

\- Series and episodes

\- Search

\- Ratings and reviews

\- Watchlist

\- Continue Watching

\- Playback progress

\- Video streaming

\- Content management
